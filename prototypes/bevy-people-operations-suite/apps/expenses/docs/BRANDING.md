# Bevy Commerce branding

The expense workspace uses the exact SVG wordmark and favicon from the existing private `bevy-hr-portal-prototype` repository (`web/bevy-logo.svg` and `web/favicon.svg`). These are reused without redrawing or recolouring the mark.

| Token | Value |
| --- | --- |
| Primary green | `#17654e` |
| Dark green | `#103e32` |
| Mint | `#eaf3ed` |
| Main text | `#18332a` |
| Muted text | `#708078` |
| Divider | `#e1e8e2` |
| Page background | `#f5f7f3` |
| System typography | Segoe UI, Arial, sans-serif |

The sidebar, active navigation, cards, focus ring and compact header follow the existing HR portal. Assets are bundled locally, including the favicon. No font download is required for the branded layout. Keep a visible demo label and Bevy Commerce title/footer. Do not replace the SVG with typed lowercase text or a different dot colour.
